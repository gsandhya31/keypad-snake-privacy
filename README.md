# Keypad Snake — Privacy Policy

This repository hosts the official Privacy Policy for the Android game **Keypad Snake** (`com.gsandhya31.keypadsnake`), served via GitHub Pages.

**Live URL:** [https://gsandhya31.github.io/keypad-snake-privacy/](https://gsandhya31.github.io/keypad-snake-privacy/)

### Summary
- No personal accounts or logins

- Minimal anonymous usage analytics via Google Firebase Analytics
- Offline-first gameplay with local high scores
